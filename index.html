# 

small projects, mostly monitoring, messaging & terminal clients

  • smokemon
    passive + active network and host monitor for macos and linux (pi / jetson), with a central hub, incident analysis, and a live fleet dashboard.
    stdlib-only on the node
  • imessage
    a clean multi-pane imessage experience with keychain credential storage, native notifications, deep links, and locally-fetched rich link previews.
    tauri · react · typescript
  • imessage-tui
    a sleek keyboard-first terminal client for imessage, backed by a bluebubbles-compatible server.
    go · bubble tea
  • slack_rust
    a lightweight terminal-native slack client built with rust and ratatui. multi-workspace, multi-pane, real-time via socket mode, with inline image previews via the kitty graphics protocol.
    rust
  • telegram_rust
    a fast, keyboard-first telegram client for terminal workflows. for people who live in panes, move quickly with shortcuts, and want multi-chat focus without leaving the shell.
    rust
